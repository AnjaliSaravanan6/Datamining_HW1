# Datamining_HW1
#Iris Dataset Classification

This assignment uses the Iris dataset to build a Decision Tree Classifier using sklearn

**What the program does:**

1. Load the Iris Dataset using scikit-learn.
2. Split the dataset into 80% train and 20% test sets.
3. Classifies using Decision Tree Classifier.
4. Create a pipeline with Standard Scalar and the classifier.
5. Finds the training and testing time.
6. Evaluates the model's prediction on the test data and gives model accuracy.
7. Creates scatterplots and generates a confusion matrix

**Results:**
1. Training time
2. Testing time
3. Model Accuracy
4. Confusion Matrix
5. Scatterplots for analysis
